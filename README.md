# CaféLoop Loyalty

Construye la primera versión visual de mi SaaS llamado CaféLoop, una plataforma de fidelización para cafeterías.

Quiero una aplicación web responsive, elegante, minimalista y en español.

Crea estas páginas:

Página pública de una cafetería de demostración, con nombre, horarios, menú, promociones y enlace a reseñas de Google.

Página de registro e inicio de sesión de clientes.

Tarjeta de fidelización con ocho espacios para sellos, progreso y recompensa.

Panel privado para empleados con un formulario para registrar una compra.

Panel del propietario con estadísticas básicas.

Utiliza datos ficticios para la demostración. Diseña la navegación y las pantallas primero. No simules que una compra real queda registrada ni que los sellos son seguros hasta que exista un backend conectado.

No agregues pagos, notificaciones automáticas ni integración con Wallet todavía.
